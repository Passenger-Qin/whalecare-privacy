鲸护 隐私政策

生效日期：2026-10-18
适用应用：鲸护（包名 com.qinnan.healthguard）

1. 我们收集哪些信息

  • 你主动填写的健康记录：体重、体脂、睡眠、备注；
  • 你主动填写的健康档案：体检结果、复查计划等；
  • 应用设置：模型地址、模型名、API Key、电脑守护地址与 token；
  • 从电脑守护读取的状态：更新时间、破戒次数、AI 任务、关机状态（仅局域网）；
  • 你主动导入的 status.json、周报或截图文件。

2. 信息如何存储

  • 健康记录、设置和健康档案保存在你手机本机的应用 Preferences 中；
  • API Key 和电脑守护 token 仅存本机，不写入日志、不上传到我们的服务器；
  • 应用没有自建云端账号系统，不收集通讯录、位置、相册或广告标识。

3. 信息如何共享

  • 只有当你主动使用 AI 问答时，对话内容和健康档案才会发送到你配置的第三方大模型 API（例如 DeepSeek）；请同时遵守该服务商的隐私政策；
  • 电脑状态通过你填写的局域网地址读取，不经过我们的服务器；
  • 除上述情况或法律要求外，我们不会向第三方共享你的信息。

4. 权限说明

  • 网络权限：用于 AI 问答和局域网读取电脑状态；
  • 文件选择：用于导入 status.json / 周报；
  • 本版本不自动读取华为运动健康数据；如后续接入 Health Kit，会另行征得你的授权。

5. 你的权利

  • 你可以在应用内修改或清空健康记录、健康档案和设置；
  • 卸载应用会删除本机保存的数据；
  • 你可以随时停止使用 AI 问答。

6. 未成年人

本应用面向成年人健康管理，不专门面向儿童；不建议 14 岁以下儿童独立使用。

7. 免责声明

本应用提供的是健康管理与就医指路信息，不构成医疗诊断或处方；急症请立即就医或拨打 120。
